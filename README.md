# Tuite - Tuition Management SaaS Platform

Welcome to the **Tuite** monorepo! This platform is a full-stack, multi-tenant SaaS designed for tuition centers and academies to manage their operations, students, teachers, and communications effectively.

## 📚 Documentation

To keep the project organized and easy to navigate, all detailed documentation has been moved to the `docs/` folder. Please refer to the relevant documents below depending on your role and what you are looking for:

- **[📖 Product Requirements & Overview](./docs/product-requirements.md)**: Details about user roles, core features, and the product roadmap.
- **[🗺️ Software Development Roadmap](./docs/roadmap.md)**: The detailed 6-phase development plan.
- **[🚀 Onboarding & Local Development](./docs/onboarding.md)**: Instructions on how to set up the project locally, configure environment variables, run the dev servers, and execute tests.
- **[🏗️ Architecture & Security](./docs/architecture.md)**: A deep dive into the Turborepo monorepo structure, shared packages, and strict multi-tenancy security rules that must be followed.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Build the shared packages and applications
npm run build

# 3. Start development servers
npm run dev
```

Happy coding! 🎉
